01 · Production system · Built and run by me

An order system for a food and beverage supplier

Orders arrive by email. The system reads them, checks them against the ERP and creates the sales order, so the team only steps in when something doesn't add up.

  • Watches a Microsoft 365 order inbox and sorts real orders from replies and noise.
  • Reads order emails and their attachments.
  • Checks each order against live ERP data: customer, SKU, unit vs case, price.
  • Creates the sales order through the ERP's API.
  • Flags anything it can't trust for a person instead of guessing.
  • Checks new senders (SPF and DKIM) before trusting them. New features ship switched off.

    03 · Machine learning research · DOST-funded thesis

    Computer vision for soil classification

    Soil scientists classify soil by matching its colour against a Munsell chart by eye. My thesis builds the tools to do that from an image.

    • Munsell Chart extraction tools for standardised soil colour analysis.
    • Computer vision pipelines for automated colour detection.
    • Structured datasets for training soil classification models.
    • Models deployed on Hugging Face for public access and reproducibility.
